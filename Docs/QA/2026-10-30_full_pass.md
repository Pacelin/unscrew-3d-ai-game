# QA: полный прогон почти финальной сборки — 2026-10-30

Исполнитель: агент qa-tester. Ветка `master` @ `346e236`. Unity 2022.3.62f2, редактор (Play Mode, Game view), Windows 11.
Код игры не правился. Скриншоты: `Docs/Screens/qa_*.png` (уменьшены в 2 раза для репозитория).

## Итог

- **Critical: 0, Major: 1, Minor: 9** (из них №8 — известное решение по данным уровней). Крэшей, исключений, софтлоков и предупреждений в консоли нет ни на одном шаге.
- Тесты: dotnet `test.sh All` **300/300**, Unity EditMode (`Unscrew.Core.Tests`) **300/300**, `UiSpecCheck.Run()` **150/150** в пределах ±2 единиц на 1080×1920, 1080×2340 и 1536×2048.
- Бот (GreedyPolicy через `GameFlow.TapBolt`, живой view, анимации ×3) прошёл **все 20 уровней кампании и бесконечные 21 и 30**, ошибок и предупреждений в консоли нет.
- Правила, бустеры, экономия, магазин, сохранение и бесконечный режим работают по `Plan.md` §1–3. Все найденные баги относятся к UI и визуалу.

### 3. Правила
- **Полный буфер без поражения:** L6, 5/5 лунок заняты, 17 доступных болтов подходят к открытым коробкам → сессия `Playing`, экран поражения не появляется (`qa_rule_full_buffer_playing.png`). Красная пульсация последней свободной лунки — это предупреждение, так задумано.
- **Поражение только при отсутствии ходов:** `RunToLose` → `Lost` при 6/6 лунках и 3 доступных неподходящих болтах; экран «Out of moves!» (`qa_lose_1080x1920.png`).
- **Экран поражения:** «Use +1 Hole ×N», «Continue 100», «Restart level».
  - Continue при 75 монетах: кнопка серая с красной ценой, по нажатию — тост и открытие магазина, монеты не списаны.
  - Continue при 575 монетах: −100, +1 лунка, `Playing`, следующая цена 150.
  - ExtraSlot с экрана поражения: −1 шт, +1 лунка, `Playing`.
  - Restart: новая загрузка, лунок снова 5, цена продолжения сброшена до 100.
- Не проверен вариант поражения без доступных болтов (текст «bolts are stuck», только Restart): его трудно воспроизвести вживую.

## Что не проверялось
- Реальное устройство и Android-сборка, мультитач, вырезы экрана, системная пауза (`OnApplicationPause`).
- Настоящий ввод мышью/тачем по `BoardInput`: тапы шли через `GameFlow.TapBolt`. Вращение модели проверено через `LevelView.Orbit`.
- Звук и вибрация, сохранение переключателей звука/вибрации.
- Экран поражения в варианте «без доступных болтов».
- PlayMode-тесты: в проекте их нет.

## Замечания по QA-хукам (не баги игры)
- `DebugAutoplay.RunCampaign` / `GameFlow.StartLevel` не закрывают экран победы и попап открытия: после прогона они остаются висеть.
- `PlayerState.CompleteLevel` начисляет награду по `Progress.CurrentLevel`, а не по показанному уровню. При обычной игре они совпадают; расходятся только при ручном `StartLevel(n)`.
