# QA 2026-11-05 — Расстановка по конфигам (bake 7), скилл запекания, туториал-палец

## Задача 1: позиции строго из конфигов + перезапекание доступности

- Все `headLift` обнулены: позиции болтов = исходный конфиг `UnscrewFirst20/Data` (решение геймдизайнера; посадка
  ComputeSeat отключена флагом `ApplyHeadLift=false`, правило 1 — отчёт-only).
- Доступность перезапечена по скиллу **`level-bake`** (новый, `.claude` + `.kimi-code`): меню Unscrew → Bake Levels или
  execute_code с флагами `ApplyHeadLift=false, ApplyVisibilityRule=false`. Все 20 уровней `valid=True`, headLift=0
  на диске проверен скриптом.
- Тапаемость через реальный ввод восстановлена прежним runtime-authoritative циклом (repair-лифтов на живой сцене
  отказа → `Tools/apply_lift_patches.py`): итерации 155→15→10→6→2→0 патчей. **Итог: input-кампания 1..20 — 0 дедлоков,
  0 ремонтов на финальной итерации**: 16 уровней Won через имитацию ввода; L5/L8/L19/L20 — жадные проигрыши бота,
  все подтверждены проходимыми солвером (Won 87/81/99/111 ходов).
- Итоговые данные: конфиг-позиции + ~190 минимальных ремонт-лифтов (в основном «чашечные» болты L6/L7/L11/L17–L19).

## Задача 2: палец туториала

- **Баг**: после тапа палец не исчезал — цель мгновенно перекидывалась на следующий болт (1 кадр скрытия), плюс слепой
  ретаргет каждые 0.5 c дёргал палец между болтами.
- **Фикс** (`Onboarding.ShowTutorial`): при увеличении `MovesMade` — пауза пальца 1.1 c (SetVisible(false)), затем
  показ на следующем валидном болте; периодический ретаргет заменён проверкой валидности цели (снят / недоступен /
  цвет не влезает в открытую коробку / **не тапается сейчас** — луч из камеры через шляпку должен бить по этому болту).
- Проверено в Play Mode (сброс PlayerPrefs): палец целится в тапаемый болт (тап снимает именно его: 3→7→5,
  moves 1→3), после каждого тапа скрывается, после 3 тапов туториал завершается и сохраняется.
- Типсы бустеров: палец на кнопке, баббл над панелью (скриншот `Docs/Screens/tutorial_tip_extraslot.png`);
  `MarkTipSeen` теперь подписан на `Flow.OnBoosterUsed` — типс гаснет при любом реальном использовании бустера
  (раньше только по клику на кнопку); под попапами/дрелью/тоастом палец скрывается (проверено).
