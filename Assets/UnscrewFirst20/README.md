# Unscrew — 3D-ассеты первых 20 уровней

Готовые сборки **уровней 1–20 текущей кампании**: 692 отдельные детали и 1 611 расставленных болтиков. Модели, материалы, текстуры и исходные точки крепления сохранены. Каждую деталь и каждый болтик можно использовать отдельно.

## Перенос в Unity

Проверено в **Unity 2022.3.62f2 с Universal Render Pipeline 14.0.12**.

1. Склонируйте этот репозиторий.
2. В своём проекте установите **Universal RP 14.x**. Материалы используют URP/Lit; для другого рендерера их нужно преобразовать.
3. Скопируйте `Assets/UnscrewFirst20` вместе с `Assets/UnscrewFirst20.meta` в `Assets` своего проекта. Сохраняйте все `.meta` внутри папки.
4. Перетащите `Assets/UnscrewFirst20/Levels/Level_01.prefab` в свою сцену. Остальные уровни называются `Level_02` … `Level_20`.

Это набор ассетов для импорта в свою игру. Корень репозитория не является отдельным Unity-проектом.

## Перенос в другой движок или 3D-редактор

Откройте любой файл `GLB/Levels/Level_01.glb` … `Level_20.glb`. Геометрия, текстуры и базовые PBR-материалы встроены в каждый GLB: внешние файлы для импорта не нужны. Детали и болтики остаются отдельными объектами, геометрия не объединена.

`GLB/Bolts/Bolt_00.glb` … `Bolt_11.glb` — самостоятельные болтики всех 12 цветов. Unity-варианты лежат в `Assets/UnscrewFirst20/Bolts/Prefabs`.

## Устройство уровня

```text
Level_01
└── Assembly                 исходный общий поворот и масштаб
    ├── Model                отдельные снимаемые детали
    │   ├── деталь 0
    │   └── …
    └── Bolts
        ├── Bolt_000_Owner_000
        └── …
```

- `Model` содержит исходную модель с сохранённым порядком и локальными трансформациями деталей.
- `Bolts` содержит отдельные болтики в исходных позициях и поворотах. Их можно скрыть целиком, чтобы получить модель без крепежа.
- Суффикс `Owner_…` обозначает ID детали. Полная связь деталей и болтиков находится в `Assets/UnscrewFirst20/Data/Level_XX.json`: `parts[].boltIds`, `bolts[].ownerId` и `nodePath`.
- Исходные модели без болтиков также доступны как Unity-префабы в `Assets/UnscrewFirst20/Models/<имя>/prefab`.
- В готовых уровнях болтики **белые** (`Bolt_07`). В игре цвета выбираются случайно при запуске, поэтому фиксированной исходной раскраски для каждого болтика нет. Разрешённые цвета каждого уровня указаны в `allowedBoltPaletteIndices`; материалы всей палитры включены.

Префабы содержат только Transform, MeshFilter и MeshRenderer. Коллайдеры, физику, извлечение болтиков и правила победы получатель добавляет в своей игре. Игровые скрипты, UI, реклама, аналитика, звук и остальные уровни в этот набор не входят.

## Масштаб и координаты

Unity-префабы и JSON используют исходные координаты Unity: Y вверх, левая система координат, без изменения размера геометрии. Модель и болтики находятся под одним `Assembly`; болтики не должны дополнительно получать масштаб контейнера `Model`.

Для ручной сборки из JSON:

- `Assembly`: поворот `rootEulerDegrees`, равномерный масштаб `rootScale`.
- `Model` внутри него: позиция `modelPosition`, поворот `modelEulerDegrees`, масштаб `modelScale` (уже учитывает исходный множитель ×15).
- Каждый болтик относительно `Assembly`: `position`, поворот `eulerDegrees`, масштаб 1. Встроенный визуальный масштаб болтика уже сохранён в его префабе.

Экранный коэффициент исходной игры принят равным 1; масштабировать готовый уровень можно целиком. Если переносите болтик под деталь, сохраните его мировую трансформацию.

GLB уже преобразованы в правую систему координат glTF. При обычном импорте GLB дополнительное отражение или поворот не нужны. JSON описывает Unity-координаты; для сборки импортированного GLB используйте его готовую иерархию и имена объектов. В GLB базовый цвет, текстура и прозрачность сохранены; блеск переведён в PBR-параметры приблизительно. Исходные Unity-материалы сохранены без изменений.

## Проверка набора

Все 20 сборок импортированы и повторно загружены в отдельном Unity-проекте. Проверены наличие mesh, материалов, шейдеров, текстур и отсутствие игровых компонентов. Все 32 GLB прошли Khronos glTF Validator без ошибок и предупреждений. Инвентарь файлов и контрольные суммы находятся в `asset-manifest.json`.
